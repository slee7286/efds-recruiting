# Operational readiness

`recruiting readiness system` checks local SQLite integrity, the configured
shared API, Gmail connection state, Playwright/Chromium, TeX, Task Scheduler,
notifications, and cloud-synchronized path warnings. It does not print secrets.

Readiness is an environment report, not a claim that every ATS is supported.
Use `recruiting browser ats-status` for evidence-backed provider capability and
fixture counts.
