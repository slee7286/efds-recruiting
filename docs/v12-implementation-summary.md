# V12 implementation summary

V12 adds explicit ATS capability levels, conservative detection for additional
providers, local browser attempts/checkpoints, Workday parser-observation
storage, privacy-safe diagnostics and fixture capture, local background run
history/locking, job-alert rules, and Windows Task Scheduler contracts.

Workday and iCIMS remain partial/experimental outside their proven common
fields. Gmail OAuth and a real Windows executable/scheduler installation remain
environment-dependent. The final-submit gate, CAPTCHA/authentication pauses,
and local-only private-data boundary remain hard invariants.
